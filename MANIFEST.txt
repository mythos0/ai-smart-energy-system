FOLDER MAP
==========

scripts/                        All pipeline code (run in numbered order)
  01_prepare_data.py            Download UCI dataset -> clean -> hourly resample -> features
  02_train_forecast.py          Train 8 forecasting models (naive x2, Ridge, ETS, RF, XGBoost, LightGBM, LSTM)
  03_anomaly.py                 Anomaly detection: residual z-score, Isolation Forest, One-Class SVM, LSTM autoencoder
  04_figures.py                 Generate all 7 publication figures
  05_test_web.py                Local web app test suite (endpoints + UI)
  06_build_notebook.py          Build the Kaggle training notebook

notebooks/
  training_pipeline.ipynb       Complete Kaggle-ready training notebook (public)

data/
  hourly_full.csv               Hourly aggregated dataset (Dec 2006 - Nov 2010, ~34k rows)

models/                         All trained models
  ridge.joblib                  Ridge regression
  random_forest_compressed.joblib  Random Forest (55 MB, compressed)
  xgboost.json                  XGBoost - BEST FORECASTER (RMSE 0.588 kW)
  lightgbm.joblib               LightGBM
  lstm_forecaster.pt            PyTorch LSTM direct multi-step forecaster
  lstm_autoencoder.pt           PyTorch LSTM autoencoder (anomaly detection)

results/                        Code output files
  forecast_metrics.json         Test metrics for all 8 forecasters (RMSE/MAE/MAPE/R2)
  test_predictions.csv          Full test-period predictions of all models
  anomaly_metrics.json          Detection metrics (ROC-AUC, PR-AUC, F1, per-type recall)
  anomaly_residual_scores.csv   Per-hour z-scores of the test period
  anomaly_case_study.json       Strongest real anomalies found (2010)
  lstm_training_history.json    LSTM train/val loss curves

figures/                        Publication figures (also embedded in the paper)
  fig1_dataset_overview.pdf     Raw time series + daily profile + missing data
  fig2_seasonality.pdf          Weekly/monthly seasonality + ACF
  fig3_model_comparison.pdf     Leaderboard bar chart + skill vs baseline
  fig4_forecast_quality.pdf     Example 24 h forecast + error decomposition
  fig5_importance_lstm.pdf      XGBoost feature importance + LSTM training curves
  fig6_anomaly_results.pdf      ROC/PR curves + per-type recall heatmap
  fig7_anomaly_casestudy.pdf    Real anomaly case study (Nov 2010 events)
  web_forecast.png              Web dashboard screenshots
  web_anomaly.png
  web_models.png

paper/                          Research paper (10 pages, journal style)
  final_paper.pdf               Final compiled PDF (DIU CSE authors)
  main.tex + refs.bib           LaTeX source
  latex_source.zip              Self-contained LaTeX package (compile-ready)
  cover.html                    HTML cover page (A4, print-ready)
  main.pdf                      Identical build output

web/                            Deployable Flask web application (what runs on Render)
  app.py                        Flask server + REST API + XGBoost inference
  templates/index.html          Chart.js interactive dashboard
  requirements.txt              Python dependencies (incl. scikit-learn fix)
  model/                        Deployment artifacts (XGBoost model + data + results)
  (render.yaml at repo root configures the Render deployment)

ROOT FILES
  README.md                     Full project documentation + repro guide
  render.yaml                   Render Blueprint (rootDir: web, gunicorn, health check)

KEY RESULTS
============
  Best forecaster : XGBoost  - RMSE 0.588 kW, 22.4% skill over seasonal naive
  Runner-up       : LSTM      - RMSE 0.592 kW, lowest MAE/MAPE
  Anomaly detector: residual z-score - ROC-AUC 0.885, F1 0.482
  Dataset         : UCI Individual Household Electric Power Consumption (2.08M rows)

HOW TO RUN
==========
  Training pipeline : python scripts/01_prepare_data.py -> 02 -> 03 -> 04
  (or open notebooks/training_pipeline.ipynb in Kaggle - zero setup)
  Web app locally   : cd web && pip install -r requirements.txt && python app.py
  Paper             : cd paper && tectonic main.tex
