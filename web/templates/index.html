AI Smart Energy System

Day-ahead electricity consumption forecasting and anomaly detection for a single household. XGBoost forecaster benchmarked against 7 models (22.4% RMSE improvement over the seasonal-naïve baseline), with residual-based anomaly detection (AUC 0.885). Full methodology in the accompanying research paper.

REST API

All endpoints return JSON. Base URL is this deployment's root.
GET/api/health
Service and model status.
GET/api/models
Full benchmark leaderboards (forecasting + anomaly detection).
GET/api/history?start=2010-07-01&end=2010-07-08
Actual hourly consumption (kW) between two dates.
GET/api/forecast?date=2010-07-06
Day-ahead backtest forecast for a date in the test period.
GET/api/anomaly?start=2010-11-01&end=2010-11-08
Residual z-scores and anomaly flags for a date range.
GET/api/anomaly/casestudy
Strongest anomaly events detected on the clean test set.
POST/api/forecast
Live 24-hour forecast from your own hourly readings (≥216 values, oldest first).
# live forecast example
curl -X POST https://YOUR-APP.onrender.com/api/forecast \
  -H "Content-Type: application/json" \
  -d '{"values": [1.24, 0.98, 0.87, ... ]}'

# response
{"mode": "live", "horizon_h": 24, "points": [
